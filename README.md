# Cali Weed - Product Verification Portal

Official anti-counterfeit product verification portal for Cali Weed.

## Features
- **Interactive 6-digit verification:** Scanned via QR code or manual entry.
- **Dynamic animated hero background:** Self-contained high-resolution SVG/Canvas animation.
- **Batch & Strain Telemetry:** Provides live feedback on authentic vs. invalid batch codes.
- **Strain Catalog & Imprint:** Integrated links to [cali-weed.com](https://cali-weed.com/) and verified legal notice.

## Tech Stack
- HTML5 / Modern CSS (Vanilla, Glassmorphism, Responsive)
- JavaScript (Vanilla, GSAP, Lenis Smooth Scroll)

## Deployment
Can be deployed instantly on GitHub Pages, Netlify, Cloudflare Pages, or Vercel.
